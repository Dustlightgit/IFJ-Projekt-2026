Function documentation

const LLTableEntry* ll_table_lookup(NonterminalType nonterm, TokenType terminal, int line)

Vyhleda pravidlo v LL tabulce pro dvojici neterminal a terminal.

Parameters
nonterm Neterminal (radek tabulky).
terminal Typ vstupniho terminalu (sloupec tabulky).
line Cislo radku vstupniho tokenu pro chybova hlaseni.
Returns Ukazatel na zaznam, ktery neni prazdnym pravidlem a je platny.

Funkce overi rozsah indexu, vyhleda zaznam a zkontroluje jeho platnost (znamy typ pravidla, u statickeho pravidla platnou produkci, u semantickeho nenulovy callback). Vracena pravidla jsou tedy vzdy staticka nebo semanticka. Volajici musi zajistit, ze neterminal je mensi nez NONTERM_LL_TABLE_COUNT a terminal mensi nez TOKEN_LL_TERM_COUNT, jinak jde o interni chybu (ERR_INTERNAL). Pokud pro dvojici neexistuje pravidlo, ukonci program syntaktickou chybou (ERR_SYNTAX).
