Function documentation

size_t precedence_table_index(TokenType terminal, int line)

Vrati index terminalu do precedencni tabulky.

Parameters
terminal Typ terminalu.
line Cislo radku pro chybova hlaseni, <= 0 pokud neni znam.
Returns Index v rozsahu 0 az PRECEDENCE_TABLE_SIZE - 1.

Nejprve overi token funkci token_type_validate (neplatny typ je interni chyba). Terminaly mezi TOKEN_LL_TERM_COUNT a TOKEN_EXPR_TERM_DELIMITER dostanou index vypoctem z jejich hodnoty v enumu a zabiraji souvisly rozsah od 0. Ostatni terminaly precedencni tabulky, ktere jsou v enumu TokenType mezi indexatory LL tabulky (napr. zavorky), dostanou index za timto rozsahem. Token, ktery precedencni tabulku neindexuje, zpusobi interni chybu (ERR_INTERNAL).

PrecedenceDirective precedence_table_lookup(TokenType stack_terminal, TokenType input_terminal, int line)

Vyhleda direktivu v precedencni tabulce.

Parameters
stack_terminal Terminal na zasobniku (radek tabulky).
input_terminal Terminal na vstupu (sloupec tabulky).
line Cislo radku vstupniho tokenu pro chybova hlaseni.
Returns Direktiva, ktera neni DIRECTIVE_ERROR.

Zaindexuje tabulku terminalem na zasobniku (ten je vzdy indexem tabulky, jinak jde o internich chybu) a terminalem na vstupu. Vstupni terminal, ktery precedencni tabulku neindexuje, je chyba ve vstupnim programu a program skonci syntaktickou chybou (ERR_SYNTAX). Pokud je pole tabulky prazdne (DIRECTIVE_ERROR), kombinace terminalu neni platna a program skonci take syntaktickou chybou (ERR_SYNTAX) s vypisem pouzitych indexu.
