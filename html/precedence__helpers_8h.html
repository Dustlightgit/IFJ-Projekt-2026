ParserStackEntry* parser_top_terminal(const Stack* stack, int line)

Najde terminal nejblize vrcholu zasobniku.

Parameters
stack Zasobnik parseru.
line Cislo radku pro chybova hlaseni.
Returns Ukazatel na zaznam s terminalem nejblize vrcholu, nikdy NULL.

Prochazi zasobnik od vrcholu hloubeji pomoci parser_stack_peek a vrati prvni zaznam, ktery je terminal. Tento zaznam se pouzije k indexaci precedencni tabulky a v pripade potreby se do nej vepise znacka redukce. Na dne zasobniku je vzdy terminal $, funkce proto nema selhat; pokud zadny terminal nenajde, jde o internich chybu (ERR_INTERNAL).

void parser_build_handle(const Stack* stack, SearchHandle* handle, int line)

Sestavi handle ze zasobniku.

Parameters
stack Zasobnik parseru.
handle Handle, ktery se sestavi, nesmi byt NULL.
line Cislo radku pro chybova hlaseni.

Projde zasobnik od vrcholu hloubeji az po prvni zaznam se znackou redukce (reduction_marker); tento zaznam do handle nepatri. Pokud je handle delsi nez HANDLE_MAX_LENGTH, program skonci syntaktickou chybou (ERR_SYNTAX), pokud se znacka na zasobniku vubec nenajde, jde o internich chybu (ERR_INTERNAL). Symboly se do handle ukladaji v prirozenem poradi zleva doprava, tedy od nejhloubeji ulozeneho symbolu (handle->symbols[0]) po symbol na vrcholu zasobniku, v poradi, v jakem je ocekava redukcni tabulka. Prazdny handle (znacka primo na vrcholu) funkce nekontroluje, resi ho reduction_table_lookup.

PredictorValue parser_evaluate_predictor(Token* token, PredictorValue predictor)

Vyhodnoti predikci operatoru a operandu pro vstupni token.

Parameters
token Vstupni token, muze byt zmenen z TOKEN_ID na TOKEN_ID_OPERATOR, z TOKEN_PLUS na TOKEN_PLUS_UNARY nebo z TOKEN_MINUS na TOKEN_MINUS_UNARY.
predictor Soucasna hodnota predikce.
Returns Nova hodnota predikce.

Pokud je na vstupu ID a je predpovidan operator, zmeni se typ tokenu na TOKEN_ID_OPERATOR (atribut tokenu zustava). Pokud je na vstupu TOKEN_PLUS nebo TOKEN_MINUS ze scanneru a je predpovidan operand, zmeni se typ tokenu na TOKEN_PLUS_UNARY resp. TOKEN_MINUS_UNARY. Nova predikce se pak urci podle tokenu: po ), ID, INT_LIT, DOUBLE_LIT, STRING_LIT, true a false se predpovida operator, jinak operand. ID prepsane na ID_OPERATOR je operator, takze po nem nasleduje operand; nezmenene ID je operand, po nem nasleduje operator. Po + a - (binarnich i unarnich) nasleduje vzdy operand.
