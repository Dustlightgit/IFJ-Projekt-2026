void special_action_id(SemanticContext* ctx, void* semantic_pointer, ContextAnnotation annotation, const Token* token)

Specialni akce pro token ID.

Parameters
ctx Semanticky kontext, do nej se uklada vytvoreny AST uzel.
semantic_pointer Ukazatel ulozeny u symbolu ID na zasobniku.
annotation Kontextova anotace ulozena u symbolu ID na zasobniku.
token Vstupni token ID ze scanneru. Token po skonceni akce uvolni parser_match, akce proto musi text, ktery chce uchovat, zkopirovat.

Jadro ji vola, kdyz je na vrcholu zasobniku terminal ID a na vstupu je take ID, a to pred porovnanim a uvolnenim tokenu funkci parser_match. Zpracuje tedy kazdy token ID vcetne jeho atributu. Obvykla akce bude podle anotace pripojit nazev ID k uzlu urcenemu ukazatelem (napr. nazev funkce nebo citace cyklu for), pripadne vytvorit uzel AST pro ID.

Vzdy vypise informaci o potkanem ID na stderr. Podle anotace pak:

  • CONTEXT_ID_COMMAND: vytvori AST uzel pro ID (Expr typu EXPR_VARIABLE) a ulozi ukazatel na nej do ctx->id_expr, odkud ho vezme jadro parseru.
  • ostatni anotace: zatim nic dalsiho (pozdeji nejspis interni chyba).

void* special_action_precedence_preprocessing(Token* input_token)

Specialni akce predzpracovani vstupniho terminalu precedencniho parseru.

Parameters
input_token Vstupni token, nesmi byt NULL. Token se nemeni, akce si text atributu predava funkci expr_new_*, token ho uvolni pozdeji parser_advance.
Returns Ukazatel na vytvoreny uzel AST (Expr *), nebo NULL pro token bez atributu.

Jadro precedencniho parseru ji vola jednou pro kazdy vstupni token, a to po vyhodnoceni prediktoru (token je tedy pripadne uz prebarveny z TOKEN_ID na TOKEN_ID_OPERATOR) a pred jeho zpracovanim a uvolnenim. Atribut tokenu je tak zpracovan driv, nez ho parser_advance uvolni.

Pro tokeny s atributem vytvori uzel AST a vrati ukazatel na nej:

  • TOKEN_ID a TOKEN_ID_OPERATOR: expr_new_variable (jmeno z atributu),
  • TOKEN_INT_LIT: expr_new_int,
  • TOKEN_DOUBLE_LIT: expr_new_double,
  • TOKEN_STRING_LIT: expr_new_string. Pro ostatni tokeny vrati NULL.

Vraceny ukazatel jadro ulozi jako semanticky ukazatel terminalu na zasobniku precedencniho parseru, terminaly s atributem tedy na zasobniku jsou uz uzlem AST a semanticka akce redukce literalu nebo ID na E ukazatel pouze preda. Pokud se ID nebo ID_OPERATOR nakonec nepouzije jako listova promenna (napr. nazev volane funkce nebo ID pouzite jako infixovy operator), vezme se z uzlu jmeno, vytvori se skutecne potrebny uzel a pomocny uzel se uvolni. Tento zpusob umoznuje, aby atribut tokenu zustal uchovan v uzlu AST a nebylo ho treba nikam jinam kopirovat.

Akce se neprovadi na pocatecnim terminalu, ktery prediktivni parser predava precedencnimu parseru (jadrova pravidla 32 a 33); u nej prediktivni parser predava uzel AST rovnou jako semanticky ukazatel.

void special_action_execute_expr_rule(ParserContext* ctx, Stack* stack, const AnnotatedSymbol* top)

Specialni akce provedeni pravidla pro vstupni terminal, kterym smi zacinat vyraz.

Parameters
ctx Spolecny kontext parseru, z nej se bere cislo radku pro chybu.
stack Zasobnik prediktivniho parseru, na nej se vklada produkce.
top Neterminal odebrany z vrcholu zasobniku spolu s jeho semantickym ukazatelem a kontextovou anotaci.

Jadro ji vola, kdyz je na vstupu terminal, ktery neindexuje LL tabulku, ale muze jim zacinat vyraz. Tato situace je pri volani jiz overena, funkce vstupni terminal nijak nekontroluje. Podle neterminalu z vrcholu zasobniku vybere pravidlo, ktere se pro vyraz na vstupu pouzije, a provede ho vlozenim prave strany staticke produkce na zasobnik (zadne z vybranych pravidel nema semantickou akci). Neterminal musi byt v dobe volani uz odebrany ze zasobniku, jeho semanticky ukazatel a anotaci predava jadro v top a funkce je podle pravidla pro staticke produkce zkopiruje do vsech vlozenych symbolu.

Mapovani neterminalu na pravidla gramatiky:

  • NONTERM_BLOCK_OR_EXPR: pravidlo 20,
  • NONTERM_COMMAND: pravidlo 45,
  • NONTERM_COMMAND_LIST: pravidlo 23,
  • NONTERM_COMMAND_SIMPLE: pravidlo 30,
  • NONTERM_RETURN_VALUE: pravidlo 35,
  • NONTERM_BLOCK_OR_COMMAND: pravidlo 44,
  • NONTERM_THEN_BRANCH: pravidlo 56,
  • NONTERM_OPTIONAL_ELSE: pravidlo 49,
  • NONTERM_EXPR_OR_INDENT_EXPR: pravidlo 52,
  • NONTERM_ELSE_TERNARY_IF: pravidlo 54.

Pro jiny neterminal skonci program chybou ERR_SYNTAX s hlasenim "LL Parser: Neni mozne zvolit pravidlo.".

void special_action_expr(void* ptr, ContextAnnotation annotation, Expr* expr, int line)

Ulozi hotovy vyraz podle kontextove anotace.

Parameters
ptr Semanticky ukazatel ulozeny u neterminalu, jehoz vyraz se uklada.
annotation Kontextova anotace ulozena u tohoto neterminalu.
expr Hotovy vyraz, funkce prebira jeho vlastnictvi.
line Cislo radku pro uzly AST a chybova hlaseni.

Vola ji vyrazovy parser po dokonceni vyrazu. Podle anotace vyraz ulozi na misto urcene ukazatelem (hodnota returnu, inicializace promenne, hodnota prirazeni, podminka cyklu while nebo if, zdroj nebo straz cyklu for). Pri ostatnich anotacich se vyraz prida jako samostatny prikaz do bloku ziskaneho funkci target_block. Drive ast_attach_expr v semantic_actions.*.
