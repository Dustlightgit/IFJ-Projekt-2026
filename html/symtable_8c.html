Symbol* symtable_define_func(SymTable* table, const char* name, FuncDef* def)

Definuje uzivatelskou funkci v globalnim rozsahu.

Parameters
table Tabulka symbolu.
name Jmeno funkce.
def Definice funkce v AST (nevlastni).
Returns Novy symbol, nebo NULL, kdyz funkce stejneho jmena uz existuje (chyba 4).

Funkce se definuje do globalniho rozsahu bez ohledu na aktualni rozsah. Parametry a navratovy typ se opisou z definice, NULL return_type znamena neznamy. Volat pro vsechny funkce driv, nez se zacnou analyzovat jejich tela.
