void parser_execute_reduction(const ParserContext* ctx, Stack* stack)

Provede redukci na zasobniku precedencniho parseru.

Parameters
ctx Kontext parseru, pouziva se z nej cislo radku vstupniho tokenu.
stack Zasobnik precedencniho parseru.

Vola se, kdyz precedencni tabulka prikazala provest redukci. Funkce:

  1. Sestavi handle ze zasobniku (parser_build_handle).
  2. Vyhleda v redukcni tabulce semantickou akci (reduction_table_lookup).
  3. Zavola akci, handle je v tu chvili jeste na zasobniku. Akce vrati pres AnnotatedSymbol symbol, semanticky ukazatel a anotaci noveho zaznamu.
  4. Vyklidi handle ze zasobniku (tolikrat parser_stack_pop, kolik je delka handle).
  5. Smaze znacku redukce ze zaznamu na vrcholu, protoze redukce, kterou ohranicovala, byla provedena.
  6. Vlozi na zasobnik zaznam s redukovanym neterminalem a informacemi od akce, bez znacky redukce.

Chyby handle a vyhledani resi volane funkce (ERR_SYNTAX pri prilis dlouhem handle nebo neexistujicim pravidle). Pokud akce nevrati neterminal, jde o internich chybu (ERR_INTERNAL).

bool parser_execute_directive(ParserContext* ctx, Stack* stack, bool use_specified_terminal, TokenType terminal, void* semantic_pointer)

Provede direktivu precedencni tabulky.

Parameters
ctx Spolecny kontext parseru, vstupni token je uz nacteny.
stack Zasobnik precedencniho parseru.
use_specified_terminal Je-li true, pouzije se misto vstupniho tokenu terminal v argumentu terminal a vstup se nemeni.
terminal Terminal pouzity misto vstupniho tokenu, ignoruje se, je-li use_specified_terminal false.
semantic_pointer Semanticky ukazatel noveho zaznamu, pokud se nejaky vklada na zasobnik.
Returns True, pokud byl spotrebovan vstupni token (vstup byl posunut), jinak false (redukce nebo pouzit specifikovany terminal).

Najde terminal nejblize vrcholu zasobniku (parser_top_terminal) a vyhleda direktivu v precedencni tabulce pro dvojici tento terminal a vstupni terminal. Podle direktivy:

  • DIRECTIVE_REDUCTION_EXECUTE: provede redukci (parser_execute_reduction), vstup se nemeni.
  • DIRECTIVE_REDUCTION_MARKER: nastavi znacku redukce u terminalu nejblize vrcholu a pak postupuje jako u DIRECTIVE_SHIFT_SYMBOL.
  • DIRECTIVE_SHIFT_SYMBOL: vlozi vstupni terminal na zasobnik se semantickym ukazatelem a anotaci CONTEXT_NONE. Pokud neni pouzit specifikovany terminal, posune se take vstup (parser_advance).

Neplatna kombinace terminalu (DIRECTIVE_ERROR) skonci chybou uz pri vyhledani v precedencni tabulce.

Expr* precedence_parser(ParserContext* ctx, AnnotatedSymbol* starting_terminal)

Jadro precedencniho parseru vyrazu.

Parameters
ctx Spolecny kontext parseru, vstupni token je uz nacteny.
starting_terminal Volitelny pocatecni zaznam zasobniku (symbol, semanticky ukazatel a anotace), nebo NULL.
Returns Ukazatel na vytvoreny podstrom vyrazu, prozatim NULL.

Zpracuje vyraz ze vstupniho proudu sdileneho pres ctx a vrati ukazatel na vytvoreny podstrom. Pri chybe ukonci program pres error_exit. Funkce si vytvori vlastni zasobnik, takze se muze rekurzivne volat (napr. pro ternarni if).

Volitelny pocatecni zaznam se pouziva jen ve specialnim pripade jadrovych pravidel 32 a 33 LL gramatiky, tedy pri rozliseni prirazeni od vyrazu zacinajiciho ID, kdy je ID uz zpracovano LL parserem. Ve vetsine pripadu je NULL.

Stavba stromu zatim neprobiha, funkce prozatim vraci NULL, protoze NULL vraci i callbacky.
