void parser_advance(ParserContext* ctx)

Posun ve vstupnim proudu dale. Kontroluje take koncovou carku.

Parameters
ctx Spolecny context parseru.

Uvolni soucasny token a zavola pritele scannera, aby dodal dalsi. Veskere zpracovani tokenu tedy musi probehnout jeste pred zavolanim teto funkce. Typ noveho tokenu overi funkci token_type_validate (neplatny typ je interni chyba).

Funkce take kontroluje zakaz dvou po sobe jdoucich carek a koncovou carku v seznamu. Kontrola je tedy spolecna pro oba parsery.

void parser_context_init(ParserContext* ctx)

Inicializuje kontext parseru a nacte prvni token ze vstupu.

Parameters
ctx Kontext parseru k inicializaci.

Vsechny hodnoty nastavi na nulove, potom zavola parser_advance, ktery ziska prvni vstupni token. Scanner musi byt pripraveny pred volanim.

void trace_rule(bool is_predictive_parser, int rule_number, int line)

Vypise pouzite pravidlo a cislo radku na stderr (ladici vystup).

Parameters
is_predictive_parser True pro pravidlo prediktivniho (LL) parseru, false pro pravidlo precedencniho parseru.
rule_number Cislo pravidla.
line Cislo radku vstupu.

Format vystupu urcuje parametr is_predictive_parser. Pravidla prediktivniho (LL) parseru se vypisuji jako "LL Parser: Pravidlo L<cislo> (radek <radek>)", pravidla precedencniho parseru jako "Precedencni parser: Pravidlo E<cislo> (radek <radek>)".
