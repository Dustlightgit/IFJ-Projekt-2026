void* grow_array(void* array, int count, size_t elem_size)

Zvetsi dynamicke pole o jeden prvek.

Parameters
array Ukazatel na stavajici pole nebo NULL.
count Aktualni pocet prvku v poli pred zvetsenim.
elem_size Velikost jednoho prvku pole v bajtech.
Returns Ukazatel na zvetsene pole.

Pokud je ukazatel na pole NULL (prazdne pole), alokuje pole pro jeden prvek. Pri selhani alokace ukonci program volanim error_exit s kodem ERR_INTERNAL.
